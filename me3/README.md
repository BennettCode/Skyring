# me3/: Elden Ring loader profiles

- `skyrim-x-er.me3`: dev profile that loads `build/er-plugin/skyrimxer_er.dll`.
- me3: https://github.com/garyttierney/me3 · docs: https://me3.help
- me3 launches the game without EAC, so it's **offline only**. Never launch modded ER through Steam's normal path or `start_protected_game.exe`.
